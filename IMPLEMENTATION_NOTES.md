# Prepwise UI refinement notes

This release applies the agreed soft, elegant and professional visual direction to the latest working project copy.

## Design changes
- Warm ivory page background, white surfaces, ink text, muted violet accents and sage success states.
- Consistent high-contrast primary and secondary buttons, with comfortable control heights.
- Readable form labels and placeholder contrast.
- Consistent surface borders, restrained shadows and card treatment.
- Authentication panels updated to match the warm brand palette.
- MCQ answer choices have clear default, hover and selected states.
- Visible keyboard focus and mobile layout refinements.
- Brand and document metadata use Prepwise.

## Feature preservation
This is a styling/brand pass on the previous working copy. Existing authentication, MCQ practice, scoring, AI feedback, performance history, and resume generation source files are retained.

## Verification
Run `npm install` in both `Backend` and `Frontend` if needed, configure each `.env` from its `.env.example`, then run the documented dev commands. Live MongoDB/Gemini/browser workflows must be verified in the user's environment.
